## Hébergement

Le site est statique (HTML, CSS et JavaScript). Cloudflare est connecté au dépôt GitHub et redéploie automatiquement chaque modification envoyée sur la branche `main`.

## Fichiers principaux

- `index.html` : textes et structure du site.
- `css/style.css` : design, affichage mobile et animations.
- `js/script.js` : menu mobile, filtres, galerie, formulaire et cookies.
- `images/` : logo et images locales.
- `rgpd.html`, `cgu.html`, `404.html` : pages complémentaires.

## Réservations

Le formulaire ouvre WhatsApp et un e-mail préremplis. Il n'exige pas de serveur.

## Mettre à jour et publier

1. Ouvrir le dossier dans VS Code.
2. Modifier les fichiers.
3. Tester `index.html` dans un navigateur ou avec Live Server.
4. Faire un commit puis un push vers la branche `main` du dépôt GitHub.
5. Cloudflare publie automatiquement la nouvelle version.
